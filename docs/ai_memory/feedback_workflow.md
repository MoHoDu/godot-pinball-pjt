# 지시 없이 작업하지 않는다 (2026-08-02 확정)

**규칙**: 무엇이든 형락님의 지시가 있기 전까지 작업을 시작하거나 결과물을 만들지 않는다. 먼저 어떻게 할 것인지 **계획을 말하고 승인을 받는다.**

Why: 아트 리소스는 방향이 어긋나면 리테이크 비용이 크고, 해커톤 마감(2026-08-10)까지 시간이 빠듯하다. 실제로 보드 아트는 과거에 v1~v5까지 리테이크한 이력이 있다.

How to apply:
- 조사·문서 읽기·현황 파악은 바로 해도 된다.
- 이미지 생성, 파일 작성, 프롬프트 실행, 코드 수정 등 **산출물이 나오는 행동은 반드시 계획 → 승인 → 실행** 순서로.
- 계획은 단계와 확인 필요 항목을 명시해서 제시한다.

# 작업 순서 (2026-08-02 지시)

1. **삼각형 보드** ← 먼저
2. **공** (현재 ball.png는 임시본, 제대로 다시 뽑아야 함)
3. 위 둘이 **전부 완료되면 형락님에게 알린다** → 그때 플리퍼 VFX 착수

※ 2026-08-03 실제로는 공 → VFX 순으로 진행됐다. 삼각형 보드는 아직 미착수.

# 확정된 사실 (이전 추정 정정)

- **플리퍼 `Flipper_cartoon.png`는 최종본이다.** 비율이 설계도(336×88)와 다르다는 지적은 무효. 리디자인 대상 아님.
- **삼각형 보드와 사각형 보드 둘 다 게임에 사용한다.** 택일 아님.
- **공은 임시본이다.** → 2026-08-03 캣츠아이로 재제작 완료.
- **카메라 각도(45° vs 58°)는 보류.** → 2026-08-02 해결: 각도 없음, 완전 평면 정사영.
