# 보드 표면 텍스처 방향 (2026-08-02 형락님 확정)

**보드 원판 확정** — Nano Banana 2로 뽑은 가로 목재 판자 이미지(어두운 슬레이트 블루).
**화풍은 확정 플리퍼 `Flipper_cartoon.png` 에 맞춘다.** 판자 이음선은 유지.

최종 사용 파일: `Resources/Art/board/octagonal_dark_wood_board.png` (2240×1260).
`test_flipper_board.tscn` 이 이걸 배경으로 쓴다.

## ★ 화풍 통일 — 맞출 것과 물러설 것

플리퍼와 **똑같이** 맞추면 안 된다. 동일 굵기의 검정 외곽선을 보드 전면에 깔면
배경이 전경만큼 시끄러워지고, 검수 기준 **"배경 장식이 공·플리퍼보다 눈에 띈다 → FAIL"** 에 걸린다.

| 맞춘다 | 물러선다 |
|---|---|
| 평탄 셀 채색 — 사진 텍스처 제거 | 외곽선은 **판자 이음선에만**, 전면에 안 깖 |
| 결 = 낱개로 셀 수 있는 세로 스트로크 | 스트로크 밀도는 플리퍼보다 **성기게** |
| 팔레트 (슬레이트 블루 + 청록 결) | 채도·대비는 플리퍼보다 낮게 |
| 손그림 선 두께 흔들림 | 빨강·주황·크림 액센트 사용 안 함 |

## 화풍 격차 실측

| | 플리퍼 (목표) | 보드 원판 |
|---|---|---|
| 외곽선 | 굵은 검정, 3328px 폭에서 약 12px | 없음 |
| 색면 | 완전 평탄 셀 | 중앙부 sd 15.5 |
| 결 | 끝이 뾰족한 밝은 청록 세로 스트로크, 낱개로 셈 | 사실적 균열·얼룩 |
| 조명 | 평면 | **비네팅 중앙 L60.8 vs 우끝 L19.0 (3.2배)** |
| 주조색 | `#1A3C55`, 결 `#1A516B` | `#3C4354` |

**주조색은 이미 거의 맞다.** 문제는 색이 아니라 표현 방식.

## 생성물에서 반드시 고칠 것

1. **비네팅** — 3.2배 차이. 공이 오른쪽 갈수록 배경이 급격히 어두워져 버그처럼 보인다
2. **워터마크 `kuso`** — 형락님이 넣은 게 아니라 **레퍼런스 이미지의 워터마크를 모델이 베껴 그린 것**
3. 상단 공백(약 5%)·하단 벽/보(약 5%) → 전부 판자로

## 수정 화면 vs 생성창

**화풍 전환은 생성창.** 수정 모드(`Add or remove things`)는 국소 변경용이라
전역 화풍 전환을 시키면 어중간하게 섞인다. 어차피 화풍을 바꾸면 전부 다시 그려지므로
국소 수정을 먼저 하면 그 작업이 버려진다.

## 확정 수치

- 보드 색 `#2E3A47`, 배경 `#161925`
- 빨강 액센트는 보드 표면에 넣지 않는다 — 벽·범퍼 오브젝트로만. 기능색 "빨강=피해·위험" 보호

## 레퍼런스에서 가져오면 안 되는 것

| 항목 | 왜 |
|---|---|
| 중앙 오컬트 원·문양 | 중앙은 보스 전용 ø420 |
| 흩어진 총·도구·잡동사니 | 배경이 공·플리퍼보다 눈에 띄면 FAIL |
| 텍스트·워터마크 | 허용 텍스트는 4개뿐 |
| 입체 나무 프레임·베벨·리벳 | 완전 평면 결정 위반. 보드가 화면 끝에 닿아 자리도 없음 |
| 강한 비네팅·방향성 조명 | 평면 결정 위반 |
| 코너 금속 보스·빨강 브래킷 | 표면이 아니라 별도 벽·범퍼 오브젝트로 |

## 참고 — 비주얼 가이드는 더 엄격하다

문서 `4. 보드/벽/보드밖배경` 은 **"보드에는 세계관 장식을 넣지 않는다"** 고 못 박는다.
판자 틈·강한 나뭇결·길게 이어지는 스크래치도 금지 목록에 있다.
현재 원판은 판자 이음선이 있어 문서 기준으로는 초과 상태. 형락님이 이음선 유지를 선택한 결과다.
