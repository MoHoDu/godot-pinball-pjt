## 컨셉 (v0.1, 강보현) — "눈을 잃은 장난감"
눈을 잃고 저주에 잠식된 장난감 내부에 유리눈(=공)을 발사해, 웨이브마다 저주를 해제하고,
마지막에 장난감 형상을 본뜬 저주 실루엣 보스를 쓰러뜨려 눈을 되돌려주는 다크 판타지 핀볼 로그라이트.

- 공 = 유리눈 = 플레이어 자신. **단 "유리로 만든 눈알"이 아니라 "눈처럼 생긴 보석"** → [[ball-glass-eye]]
- 플리퍼 = 장난감의 턱·팔·날개 (막대 금지). 회전축은 큰 눈/단추/나사
- 보스 = 장난감 형상을 흉내 낸 저주 실루엣. 몸체는 먹색·짙은 보라 큰 덩어리로 단순화, 공격 가능한 저주 핵만 빨강·라임
- 세션: 일반 웨이브 3회(사이마다 유물 보상·배치) → 보스 → 클리어
- 텍스트 없는 서사. 허용 텍스트는 "수리 시작 / 저주 해제 / 보스 / 수리 완료"뿐

## 비주얼 방향 (2026-07-31 개편)
**구 방향 폐기**: "미친 발명가가 용접한 처형용 핀볼 기계", 녹슨 금속·갈색/주황·반실사 다크 인더스트리얼 호러.
**신 방향**: 형태가 크고 명확한 **다크 카툰**. 저주받은 기계·도박 장치·미스터리·파괴의 쾌감은 유지.
고어는 사실적이 아니라 카툰식 캐릭터성과 과장된 반응으로.

### ★ 시점 = 완전 평면 정사영, 카메라 각도 없음 (2026-08-02 형락님 확정)
45° vs 58° 논의 종료. 카메라 틸트 없음. 아트 전반에 걸리는 결정이다.

- 광원 방향이 없다 → 한쪽이 밝고 반대쪽이 어두운 음영을 넣지 않는다
- 두께·옆면·베벨·드롭섀도가 없다 → 벽·플리퍼·범퍼 전부 위에서 본 납작한 형태
- 입체감은 **명도 단차와 굵은 외곽선**으로만 만든다. 그라디언트 음영으로 만들지 않는다
- 유리눈(공)의 하이라이트는 예외 — 재질 표현이지 광원 표현이 아니다

### 레퍼런스
- **굶지마**: 눈알+촉수 몬스터, 거친 잉크 붓선, 순수 검은 실루엣 그림자 괴물
- **컬트 오브 더 램**: 완전 검은 실루엣 + 빨간 눈 하나, 이빨 늘어선 유기적 촉수, 보라/빨강 제단
- **단간론파**: 핫핑크·마젠타 스플래터, 흑백+마젠타 강대비, 방사형 집중선, 붓글씨 타이포
- **디지털 서커스**: 역광 실루엣 라인업, 눈알 패턴 벽지, 흑백 체커보드+원색 블록, 빨강·흰색 선버스트
- **플리퍼 전용**: TPF 2019 텍사스 핀볼 페스티벌 포스터 — 단색 파랑 스크린프린트 + 두꺼운 검정 아웃라인

직접 모방 금지. 레퍼런스에서 가져올 것은 팔레트와 구조지 렌더링 방식이 아니다 → [[prompt-style-drift]]

### 기능색 (보드 테마가 바뀌어도 고정)
- 청록·아이보리 = 플레이어가 조작 가능한 것 (공, 선택된 플리퍼)
- 빨강·핫핑크·적자 = 피해와 위험
- 노랑·금색·연두 = 보상과 성공
- 보라·라임·청자 = 저주와 특수 상태
- 배경 = 먹색 남색 / 짙은 보라 / 어두운 청록

### 화면 비중
60% 어두운 배경·보드 / 25% 보드 테마 주조색 / 10% 조작 피드백 / 5% 보상·잭팟 특수 연출

### 형태 언어
큰 덩어리와 실루엣 우선. 완벽한 대칭보다 약간 비뚤어지고 찌그러진 형태.
금속=큰 하이라이트면+굵은 흠집 2~3개 / 목재=과장된 나뭇결 2~4개 / 유기물=말랑한 외곽선+점액 하이라이트 /
뼈·치아=밝은 아이보리 단순 덩어리 / 전기=굵고 짧은 번개.
사실적 녹·기름때·미세 스크래치를 화면 전체에 반복하지 않는다.

### VFX 3단계
- 일반 충돌: 작은 스파크, 선형 충격선
- 정확한 패링·콤보: 원형 파동, 색상 반전, 짧은 잔상
- 보스 타격: 큰 카툰 파편, 화면 프레임 반응, 강한 색면

화면 전체를 덮는 파티클은 보스 피격/잭팟/웨이브 성공에만.
공 VFX는 딱 3종으로 제한 → [[vfx-ball-effects]]

## 플리퍼 스펙 (기획서 v2 확정 수치)
- 1그룹 = 서브 플리퍼 2개. 방향키로 그룹 선택, Space로 그룹 동시 작동
- 서브 플리퍼 **336×88px**, 시각 최대 폭 **34px**, 충돌 두께 **24px**, 안쪽 스트로크 18px
- **회전축이 바깥쪽 끝(0%), 플리퍼 끝(100%)이 중앙 갭을 향함**
- 접촉 구역: A 축측 0~35%(속도×0.94, ±8°) / B 중앙 35~70%(×1.00, ±16°) / C 끝단 70~90%(×1.08, ±30°) / D 갭인접 90~100%(×0.84, ±10°)
- 패링 기본 배율: 비작동 0.85~0.86 / 일반 패링 1.08 / 정확한 패링 1.18
- 최종 속도 = 충돌 직전 속도 × 패링 배율 × 접촉 위치 배율
- 공 반지름 22px, 기준 해상도 1920×1080, 외곽 여백 4px
