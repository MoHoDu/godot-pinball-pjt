# 작업은 항상 3단계로 쪼갠다

2026-08-03 형락님 지시: 앞으로 아트 리소스나 결과물을 작업할 때는
**① 형태/원본 생성 → ② 텍스처 입히기 → ③ 세부 디테일** 순서로 단계적으로 진행한다.

Why: 보드 STEP1~3 파이프라인에서 검증된 방식. 한 번에 다 만들면 리테이크 비용이 크고,
단계마다 검수 지점이 생겨 방향이 어긋나도 그 단계만 되돌리면 된다.

How to apply:

- **아트·VFX·SFX 전부에 적용.** 각 단계 통과본을 다음 단계의 고정 기준(레퍼런스)으로 쓴다.
- 실루엣/형태는 AI에 맡기지 않고 수치·마스크로 확정한다 ([[board-step-pipeline]] 원칙과 동일).
- 각 단계 완료 시 형락님 검수 → 승인 후 다음 단계.

## 각 단계에서 AI가 맡는 범위 (도메인별 실증)

| 도메인 | ① 형태 = 우리가 확정 | ② 텍스처 = AI |
|---|---|---|
| 보드 | 실루엣 좌표·마스크 | Leonardo 표면 재질 |
| 공 | 껍질 윤곽·동공 크기·채움률 | Leonardo 홍채 질감만 |
| VFX ② 꼬리 | 길이·폭·테이퍼·궤적 로직 | 셰이더 밴딩·결 |
| **SFX** | **어택 트랜지언트·총 길이·레이어 밸런스 (절차적 합성)** | **ElevenLabs 재질음만** |

공통 함정: **AI는 "5종 공통이어야 하는 것"을 5번 뽑으면 5개가 다 달라진다.**
공 껍질 5종(→[[ball-reward-variants]])과 SFX 공통 어택(→[[sfx01-ball-pilot]])이 같은 이유로 걸렸다.
