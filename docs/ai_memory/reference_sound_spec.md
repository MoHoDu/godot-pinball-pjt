## 1. ★ 벽 충돌 SFX 수치 (p.62) — 구현이 지켜야 하는 유일한 정량 규격

| 항목 | 기준 |
|---|---|
| 기본 음원 수 | **3종** |
| 음원 길이 | **0.06~0.14초** |
| 피치 랜덤 | **±5%** |
| 최대 동시 재생 | **4개** |
| 동일 공 재생 간격 | **최소 0.04초** |
| 패링음 대비 볼륨 | **약 -8~-10dB** |
| 잔향 | 없음 또는 극소량 |
| 연속 충돌 | **두 번째 소리부터 약 -3dB** |

- 사각형·삼각형 보드는 **동일한 벽 충돌음**을 쓴다. 보드별로 분기하지 않는다.
- 벽 충돌은 패링·플리퍼·보스 타격음보다 **작고 짧게** 쓴다 (p.61).

### 길이 규격이 두 곳에서 다르다
공 공통 규격(p.42, p.90)은 **0.08~0.20초**, 벽 충돌 규격(p.62)은 **0.06~0.14초**다.
**겹치는 0.08~0.14초**로 만들면 둘 다 만족한다. SFX 파일럿은 그렇게 했다.

## 2. 사운드 우선순위 — 세 곳에서 반복된다 (p.42 · p.90 · p.154)

> 1. 정확한 패링 → 2. 보스 타격 → 3. 플리퍼 타격 → 4. 공과 주요 범퍼 충돌 → 5. 일반 벽 충돌 → 6. 환경음·장식음

공 충돌음과 플리퍼음이 배경음에 묻히면 안 된다.
제작 우선순위는 따로 있다 (p.15): 공·플리퍼 → 목표물·보스 → 위험 장치 → 콤보·보상 → 배경음·BGM.

**동시 재생 목소리를 선착순으로 나눠주면 이 우선순위가 깨진다.** 벽 충돌 4개가 목소리를
다 잡으면 패링이 밀린다.

## 3. 공 충돌음의 3층 구조 (p.41, p.89)

| 레이어 | 역할 | 공별로 |
|---|---|---|
| ① 어택 | 충돌 위치·타이밍 전달. 짧은 톡·탁 | **공통.** 공이 달라도 충돌 시점 인지 기준은 유지 |
| ② 재질 | 공의 물리 성격 전달 | **공별로 다름** |
| ③ 결과 | 반사·패링·강화 상태. 짧은 잔향 | 상황별 |

### 공 5종 재질음 (p.89 6-2, 상세는 p.93/95/97/101/104)

| 공 | 재질음 | 일반 충돌 | 정확한 패링 |
|---|---|---|---|
| 정속 태엽눈 | 태엽 클릭 | 공통 탁 + 유리 팅 + 작은 태엽 클릭. **피치 편차 작게** | 탁 + 밝은 유리 팅 + 짧은 종 1음 + 파동음 |
| 고무막 유리눈 | 고무 뽁 | 공통 탁 + 짧은 뽁/뿅 + 작은 유리 팅 | 탄력 있는 탁 + 유리 팅 + 튀어오르는 뿅 + 파동음 |
| 완충 젤 유리눈 | 젤 푹 | 공통 어택 + 낮은 뽁 + 짧은 푹. **유리음 약하게** | 명확한 탁 + 밝은 유리 팅 + 부드러운 파동음 |
| 납심 유리눈 | 낮은 클랙 | 낮은 유리 클랙 + 짧은 나무 둑 + 아주 작은 황동 공명 | 깊고 명확한 클릭 + 맑은 금빛 차임 + 짧은 원형 충격음 |
| 속빈 방울눈 | 속빈 유리 팅 | 맑은 속빈 유리 팅 + 작은 내부 딸랑 + 짧은 공통 어택 | 명확한 탁 + 짧은 유리 화음 + 작은 금빛 방울음 + 파동음 |

### 정확한 패링은 3레이어 공통 (p.90 6-3)
1. 플리퍼와 공이 맞닿은 **명확한 탁**
2. 성공을 전달하는 **밝은 팅**
3. 원형 링이 퍼지는 **짧은 웅/팡**

→ **공별로는 두 번째 레이어의 재질 악센트만 바꾼다.** 1·3은 공통이다.

## 4. 상황별 음색 (p.41 3-10)

| 상황 | 권장 음색 |
|---|---|
| 발사 대기 | 작은 유리 공명 + 낮은 마법 진동 |
| 발사 | 짧은 퐁 + 공기를 가르는 슉 |
| 일반 벽 충돌 | 유리구슬 톡 + 나무 블록 탁 |
| 고무·유기물 충돌 | 뽁 · 퍽 |
| 범퍼 충돌 | 탄력 있는 뽀잉 · 퐁 |
| 플리퍼 일반 타격 | 명확한 탁 + 짧은 휙 |
| 정확한 패링 | 깊은 탁 + 밝은 팅 + 원형 충격음 |
| 콤보 상승 | 짧은 음높이 상승음 |
| 보스 타격 | 탄력 있는 팡 + 낮은 충격음 |
| 눈 복귀 | 맑은 유리 공명 + 짧은 오르골 종소리 |

### 이동음은 꼬리 VFX에 연동한다 (p.38 3-9)
저속 **없음** / 일반 아주 작은 공기 마찰음 / 고속 짧고 가벼운 슈우 / 패링 직후 순간적으로 날카로운 슉.
꼬리가 길다고 지속적인 큰 제트음·레이저음을 쓰지 않는다.

### 콤보 (p.42)
음높이를 조금씩 올리고 3~5단마다 별도 성공음. 멜로디가 되어 충돌 위치를 가리면 안 된다.
콤보가 끊길 때 실패음은 **작고 짧게**.

## 5. 대상별 요약 (공 외)

- **플리퍼 (p.20)** — 선택: 딸깍·단추·나무 블록 / 작동: 스프링 압축 + 짧은 휙 / 일반 타격: 단단한 톡·탁 /
  강한 타격: 금속 쾅이 아니라 탄력 있는 쫙·팡 / 정확한 패링: 명쾌한 탁 / 복귀: 작은 태엽 떨림.
  **선택음과 작동음은 분명히 달라야 한다.** 반복 입력 시 일부 레이어를 줄인다.
- **범퍼 (p.120)** — 3층: 짧은 충돌 어택 + 재질음 + 기능 악센트.
  단추=딱+플라스틱 / 솜=푹+천 압축 / 용수철=끽+팡 / 북=통+팡 / Track=딸깍+굴림 / 대포=철컥+팡.
- **수리부품 (p.154, p.158~168)** — 톤은 "고장 난 장난감 오락기 + 태엽 장치 + 작은 인형사 공방".
  단계가 있는 부품은 **단계마다 피치를 조금씩 올려 상승 패턴**을 만든다. 딸랑 루프는 금지.
- **코인 (p.183)** — 획득 0.10~0.16초 / 정산 0.18~0.30초 / 소비 0.10~0.16초 / 부족 0.08~0.12초.
  가벼운 장난감 황동 토큰. 카지노 금화 사운드 금지. **피치 차이 2~3종**을 둔다.

## 6. 금지 음색 (p.15 · p.61 · p.90 · p.120)

> 무거운 금속 쾅 · 폭발음 · 긴 금속 잔향 · 강한 저음 충격 · 충돌마다 나는 전기음 ·
> 긴 제트음/레이저음 · 긴 루프음 · 저음만 강한 사실적 공포 사운드 ·
> 여러 장치가 동시에 같은 음색을 내는 구성

**★ 벽 충돌에 플리퍼·패링과 동일한 어택을 쓰지 않는다 (p.61).**
"공 5종은 같은 어택을 공유한다"(p.89)와 축이 다르다 — 공끼리는 공통, **오브젝트끼리는 구분**이다.

프롬프트 금지 단어는 [[sfx01-ball-pilot]]에 따로 있다 (구 컨셉 산업 호러로 끌려간다).

## 7. 리소스·구현 규약

### 필수 리소스 (p.43 MUST / p.105 12-1)
- 기본 충돌 SFX **3종 이상** · 플리퍼 타격 · 정확한 패링 · 보스 타격
- 공 종류당 **재질음 3종 이상 + 패링 악센트 1종 이상**
- **공통 어택과 재질 레이어를 분리**해서 만든다

### 노드 구조 (p.106 12-3)
`BallVisual > BodySprite · PupilSprite · Outline · Trail · IdentityParticles · ParryVFX · AudioController`

### ★ 공 데이터 리소스의 사운드 필드명 (p.106 12-4)
```
hit_material_sfx
parry_accent_sfx
```
문서가 이름을 지정하고 있다. 5종으로 확장할 때 여기에 맞춘다.

### 파일명 (p.107 12-5)
`SFX_Ball_{Clockwork|Rubber|Gel|Lead|HollowBell}_Hit_01.wav`

### 구현 원칙 (p.108 12-6)
- 정확한 패링의 **발생 시간과 공통 인지음은 모든 공에서 유지**한다
- 공별 차이는 색상·재질 악센트·파티클 형태로만
- 공이 바뀌어도 플리퍼·보스·벽 SFX의 **우선순위는 유지**
- 여러 충돌음의 **최대 동시 재생 개수를 제한**한다

## 8. 검수 체크리스트 — 사운드 (p.44 · p.109 · p.5)

- [ ] 일반 충돌과 정확한 패링이 **소리만 들어도** 구분되는가
- [ ] 공별 충돌음으로 재질과 성격이 구분되는가
- [ ] 연속 충돌 시 볼륨이 과도하게 누적되지 않는가
- [ ] 공 충돌음이 BGM·환경음에 묻히지 않는가
- [ ] 모든 충돌에 폭발음이나 긴 금속음을 쓰지 않았는가
- [ ] 선택음·작동음·패링 성공음이 서로 다른가
- [ ] 일반 타격과 강한 타격의 차이가 들리는가

## 9. 2026-08-06 시점 구현 대조

**맞는 것** — 벽 충돌 수치 전부(3종·±5%·4개·0.04초·-3dB·-8~-10dB)를 `BallAudioRules.tres`와
`ball_audio_test.gd`에 못 박았다.

**아직 어긋나는 것**

1. **벽과 플리퍼를 구분하지 않는다.** `body_entered` 하나로 같은 소리를 낸다.
   p.61이 벽 충돌에 "플리퍼·패링과 동일한 어택" 사용을 금지하므로 충돌 상대별 분기가 필요하다.
2. **우선순위 구조가 없다.** 목소리 4개를 선착순으로 쓴다. 패링은 전용 플레이어라 안전하지만
   보스·플리퍼가 붙으면 §2 순서를 지킬 장치가 필요하다.
3. **필드명이 문서와 다르다.** `hit_streams`/`parry_streams` ↔ 문서는 `hit_material_sfx`/`parry_accent_sfx`.
4. **어택이 재질음에 구워져 있다.** 파일럿 Hit 파일은 합본이다(2026-08-06 파형 실측으로 확인).
   분리본은 `docs/ball_guides/sfx/layers/`에 있다. p.105는 분리 제작을 요구한다.
