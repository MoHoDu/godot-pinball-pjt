# VFX ② 이동 꼬리 (2026-08-03)

관련: [[vfx01-mist-aura]], [[ball-texture-fixed]], [[staged-art-pipeline]], [[vfx-ball-effects]]

## 확정 스펙 (안 D1)

**꼬리는 VFX 두 개로 이루어진다** (형락님 스케치):

| | 역할 | 뿌리 폭 | 색 |
|---|---|---|---|
| ① 안쪽 레이저 | 방향을 만든다. 가늘고 경계 또렷 | **9px** | 순백 → 아이보리 `#F0E0C3` |
| ② 바깥 블룸 | 레이저를 감싸는 안개. 넓고 흐림 | **60px** | 안개 ①과 동일 청록 |

- 길이 **140px** (공 44px 기준)
- 밝기는 길이 방향 **4단 계단** — 공 뒤가 제일 밝고 끝은 투명 블룸만 남는다
- `core_root 0.20` / `bloom_root 1.35` (공 반지름 대비 비율. px 하드코딩 금지)
- **"60px"은 뿌리 폭이다.** 꼬리 중간으로 갈수록 테이퍼로 좁아진다(60px 뒤 지점에서 약 35px)

## ★ 순백 레이저는 의도적으로 가이드를 깬 것이다

레이저 휘도 **1.000** > 공 본체 **0.990**.
가이드의 가독성 우선순위(공 본체 > 발광 테두리 > 이동 꼬리)를 **뒤집는다.**

2026-08-03 형락님이 "그대로 둔다"로 결정. 되돌릴 수 있게 남긴다:
아이보리(휘도 0.93)로 낮추면 육안으로는 여전히 흰 레이저이면서 규칙을 지킨다.
강보현님 검수에서 "VFX가 공의 흐름 판단을 방해한다"로 걸리면 이 스위치를 쓴다.

## 길이 140px의 근거 — 문서 60~100px을 초과한다

안개 ①이 40px까지 퍼져 꼬리 뿌리가 묻힌다. 실측:

| 길이 | 안개 밖 노출 | 알파 무게중심 |
|---|---|---|
| 60px (문서 하한) | 19px | **+0.05R = 공 앞쪽** |
| 100px (문서 상한) | 59px | −0.06R |
| **140px (확정)** | 99px | **−0.23R** |

60px은 무게중심이 공 **앞**에 잡혀 공이 뒤로 가는 것처럼 보인다.

## ★ 문서가 이미 형태를 규정하고 있었다

비주얼 가이드 3-4 "형태 구성": 중심(가장 밝음) / 외곽 글로우(넓고 투명, 보드와 섞이게) /
보조 입자(2~5개). 즉 "부드럽게 퍼지는 외곽"은 화풍 이탈이 아니라 **문서 요구사항**이었고,
처음 만든 단일 밴딩 쐐기가 오히려 미달이었다.
형락님이 "사진처럼"이라며 준 레퍼런스도 **가이드 23~24페이지에 이미 들어 있는 이미지**였다.

교훈: 레퍼런스를 받으면 "화풍 이탈 아닌가"부터 의심하지 말고
**문서에 이미 그 형태가 규정돼 있는지 먼저 확인한다.**

## 실측으로만 잡힌 버그 (형태 단계)

- 회전을 `angle + π`로 줘서 꼬리가 **공 앞으로** 뻗었다. `make_path`가 이미 -x로 뻗는다
- 뿌리 폭이 공 반지름의 86%라 꼬리가 아니라 덩어리로 보였다
- 곡률 `1.35/L`은 낫처럼 휘었다 → `0.70/L` (끝에서 약 20도)
- 레이저를 굵히면서 블룸을 좁혔더니(구 안 C) 2겹으로 안 읽혔다.
  **블룸/레이저 ≥ 2.5배**를 유지해야 감싸는 것으로 보인다

## ② 텍스처 단계 — 구현 완료

**Line2D 는 2개가 아니라 1개다.** 두 개를 쓰면 점·폭을 매 프레임 맞춰야 하고 미세하게 어긋난다.
`width_curve` 를 블룸 테이퍼와 똑같이 맞춰두면 셰이더의 `across = |UV.y-0.5|*2` 가
곧 "그 지점의 블룸 반폭으로 나눈 거리"가 되어 한 장에서 2겹을 다 그릴 수 있다.

Line2D UV: `UV.x` = 길이 방향(점을 최신순으로 넣어 0이 공 쪽), `UV.y` = 폭 방향.

### 실측으로만 잡힌 셰이더 버그 2개

1. **꼬리 끝에서 1px 경계 완화가 레이저보다 넓어진다.** 블룸이 얇아지면
   `edge_norm = 0.9/bloom_half` 가 `core_norm` 을 넘어서 경계 램프가 레이저를 통째로 먹는다.
   → 밝기 계단이 22단으로 뭉개졌다. `clamp(..., core_norm*0.9)` 로 레이저 안쪽에 가둔다.
2. **계단이 4단이면 꼬리 끝도 25% 밝기로 남는다.** 스케치의 "끝 = 투명 상태의 블룸"이 안 나온다.
   → `core_step_drop` 을 넣어 **레이저를 블룸보다 한 계단 먼저 끈다.** 끝 알파 0.49 → 0.22.

### 인게임 영상 피드백 2건

**1. "올챙이 꼬리처럼 삼각형"** → 테이퍼 지수를 **1.0(직선)** 으로, 끝 폭을 점으로.
`bloom_power 1.6→1.0` / `core_power 1.35→1.0` / `bloom_tip 0.14→0.02` / `core_tip 0.024→0.004`.
지수가 1보다 크면 옆면이 안쪽으로 휘어 물방울이 된다. 삼각형은 반드시 1.0.
끝 폭 59.4×0.02/1.35 ≈ **0.9px** 로 수렴.

**2. "감속하면 끝쪽 잔상이 계속 남아있다"** → 궤적 점에 **수명**이 없었다.
점은 월드 좌표에 고정돼 있고, 거리 기준으로만 자르면 공이 느려졌을 때
누적 길이가 안 줄어 옛 점이 **그 자리에 얼어붙는다**(min_length_scale 0.45 × 140 = 63px 에서 정지).
→ `point_lifetime` 0.22s 추가. 끝에서부터 나이순으로 버린다.

### ★ 시뮬레이션으로만 잡힌 진짜 버그 — 느린 공에서 꼬리가 점 하나로 붕괴

수명을 넣고 시뮬레이션했더니 70px/s 에서 꼬리 길이가 **0px** 이 됐다.
원인: 간격 검사를 `_history[0]`(매 프레임 공을 따라 움직이는 "살아있는 머리")과 했다.
머리를 매 프레임 옮기므로 거리가 **늘 한 프레임치**라 `step` 을 영영 못 넘고
새 점이 확정되지 않는다. 고속에서는 한 프레임 이동이 step 보다 커서 우연히 동작했다.

→ 간격 검사는 **마지막으로 확정된 점 `_history[1]`** 과 해야 한다.
0번은 머리, 1번부터가 확정 궤적이다.

수정 후 속도별 꼬리 길이: 70px/s → 13px, 150 → 33px, 400 → 63px, 1100 → 171px.
감속 시 63px 에서 **12px 로 걷힌다**(수정 전에는 63px 에 영구 정지).

검증: `docs/ball_guides/trail_history_sim.py` — GDScript 링버퍼 로직을 파이썬으로 1:1 이식.
**원본을 고치면 이 파일도 같이 고쳐야 한다.**

### ★ 두께 3배는 시도했다가 되돌렸다

형락님 요청으로 레이저·블룸을 3배(`core_root 0.60` / `bloom_root 4.05`)로 올렸으나
인게임 영상 확인 후 **"아까보다 더 안좋아졌다"** 로 즉시 롤백.

- 블룸 뿌리 178px = **공 지름(44px)의 4배**
- 꼬리 면적 = 공의 **8.2배** (3배 전 5.4배)
- 보드 폭 2240 대비 뿌리가 8%

**교훈: 폭은 비율보다 절대 크기가 지배한다.** 블룸/레이저 비율(6.75배)은 그대로였고
검수 12종도 전부 통과했는데 인게임에서는 나빴다. 수치가 통과해도 화면 점유가
공 대비 몇 배인지를 먼저 봐야 한다. 다음에 두께를 만질 땐 **1.5배 단위로** 올릴 것.

부수 발견: 폭 상한이 `MAX_WIDTH_RATIO 4.0` 이라 `bloom_root 4.05` 가 **조용히 clamp** 될 뻔했다.
setter 가 `clampf` 로 강제 보정하는 구조라 에러 없이 값만 달라진다.
상한은 8.0 으로 올린 채로 뒀다(값 자체는 롤백했으므로 동작에는 영향 없음).

## 렌더 스크립트 함정

- **시트 생성 코드는 반드시 `if __name__ == "__main__"` 아래.** 모듈 수준에 두면
  `compose`를 import 하는 것만으로 시트 전체가 다시 그려져 멈춘 것처럼 보인다
- **moderngl 컨텍스트는 전역 재사용.** 렌더마다 create/release 하면 Xvfb에서
  20여 회 뒤 **아무 에러 없이 프로세스가 죽는다**
- 거리장은 세그먼트를 벡터화해야 한다. 파이썬 루프면 가닥 수만큼 곱해져 안 끝난다
- 셀이 패널보다 크면 옆 칸을 침범한다 — 패널 크기로 잘라서 붙일 것
