# 공 리디자인 (2026-08-03) — 원안 회귀 + 진행방향 + 축 눈 구분

관련: [[ball-glass-eye]], [[pinball-logue]], [[art-pipeline]], [[workflow-rules]]

**캣츠아이는 폐기 방향.** 형락님 선택: 기획서 원안(큰 청록 홍채 + 둥근 검은 동공 +
아이보리 외곽 + 강한 하이라이트 1개)으로 회귀. 해결 목표는 **진행방향 가독성 하나**.
제작 방식은 절차적 마스터 확정 → Leonardo 질감 (기존 공 파이프라인과 동일).

## ★ PL 정정 — 외곽선은 완벽한 원이다

비주얼 가이드 3-6에 "외곽선은 완벽한 원이 아니라 손으로 그린 듯 아주 약하게 흔들린다"고
적혀 있지만 **PL이 정정했다**: "핀볼 자체는 완벽한 원인데, 원 외곽선 **안**이 약간 비뚤어진
수작업 카툰 선 느낌이 나야 한다."

→ 잉크 외곽 실루엣은 수학적 원. 흔들림은 **내부 홍채선에만** 넣는다.
(저주파 4성분 sin 합, 진폭 7/1024 정도면 44px에서 원으로 읽히면서 손맛이 남는다)

## ★ 3-6 재질 규격 (반드시 전부 들어가야 함)

- 큰 하이라이트 1개 + 작은 보조 하이라이트 1개까지
- **외곽 한쪽에 두꺼운 반사면** ← 캣츠아이엔 없던 요소
- 내부 홍채가 완전히 가려지지 않는 **약한 투명도**
- 유리 안쪽에 **살짝 떠 있는** 홍채와 동공
- 내부 홍채선도 약간 비대칭
- 균열은 최대 1~2개, **프로토타입에서는 제작하지 않는다**

## ★ 실측 — 축 눈과 공은 크기가 거의 같다

| | 인게임 크기 |
|---|---|
| 플리퍼 축 눈 소켓 | **47px** |
| 공 | **44px** |

메모리에 "축 눈 약 70px"으로 적혀 있던 건 과대추정. 1920×1080 렌더에서 아이보리 소켓
알파 bbox로 재측정한 값이 47px이다. **크기 차이로는 구분이 안 된다.**

## ★ 핵심 발견 — 색이 아니라 덩어리 구조로 갈린다

PL 요구: "플리퍼에 달린 눈깔과 비슷해지면 안 됨."
그런데 **원안 = 축 눈의 설계도다.** 아이보리 외곽 / 큰 청록 홍채 / 둥근 검은 동공 /
흰 하이라이트 — 네 항목이 전부 겹친다. 원안을 100% 지키면 구조적으로 피할 수 없다.

**색배분으로는 안 갈라진다.** 아이보리 비중을 11%~24%까지 흔들었으나
혼동도(22px 뭉갠 뒤 Lab ΔE)가 27.8~30.3에서 거의 안 움직였다.

**갈리는 축은 하나뿐이다 — 22px로 뭉갰을 때의 덩어리 인상:**

| | 인상 |
|---|---|
| 플리퍼 축 눈 | **링** — 밝은 아이보리 테가 작은 동공을 빙 둘러싼다 |
| 공 (동공 확대) | **초승달** — 큰 어두운 덩어리 + 한쪽에 붙은 밝은 유리 초승달 |

**동공을 키우면 링이 깨지고 초승달이 된다.** 이게 유일하게 확실히 갈리는 수단이다.

## 진행방향 가독성 — 어두운 것은 앞, 밝은 것은 뒤

둥근 동공은 회전 대칭이라 그것만으론 방향이 안 나온다.
**동공을 진행방향으로 밀고, 두꺼운 반사면·아이보리를 뒤쪽에 배치**해 앞뒤 축을 만든다.

측정 지표 = 44px에서 어두운 무게중심과 밝은 무게중심의 진행축 거리(분리폭).

| 시안 | 혼동도 ΔE | 분리폭 |
|---|---|---|
| **Q 밝은 유리 + 큰 동공** ← 채택 | **31.8** | **5.92px** |
| N 큰 동공 (밝기 유지) | 30.7 | 6.11px |
| O 아이보리 제거 | 31.2 | 4.38px |
| M 원안 충실형 | 30.4 | 4.23px (링 유지 → 겹침) |
| 현재본 cats_eye | 27.8 | **0.25px** |

현재본은 아몬드가 좌우 대칭이라 **180° 뒤집어도 같아 보인다.** 이게 리디자인의 출발점이었다.

## ★ 최종 확정 (2026-08-03) — V4 큰 홍채 · 홍채 중앙 정면 응시

형락님 최종 선택은 **Q가 아니라 V4(큰 홍채)** 였고, 이어서 **홍채·동공을 정중앙**으로 모으라고 지시했다.

**정면 응시의 대가를 알고 간다** (수치로 제시하고 선택하신 것):

| | 홍채 중앙(채택) | 홍채 전진 |
|---|---|---|
| 진행방향 분리폭 | 1.15px | 4.70px |
| 축 눈 혼동도 ΔE | 24.9 | 29.0 |

혼동도 24.9는 구본 캣츠아이(27.8)보다도 낮다. 축 눈이 동심원인데 공도 동심원이 되면서
유일하게 갈라주던 비대칭이 사라졌기 때문이다. **방향 표시는 VFX ② 이동 꼬리가 담당하게 된다.**

## ★ PL 화풍 지시 — 굶지마 잉크선

PL이 굶지마 눈알 몬스터를 지목. 가져온 것: 잉크선 두께가 크게 널뛰고 한 방향으로 붓 압력이 실림.
버린 것: **빨간 촉수·다리·핏줄** (기능색 빨강=피해 규칙 보호).

레퍼런스 이미지를 Leonardo에 통째로 넣지 않고, **우리 공에 선질만 입힌 화풍 목표판**을 만들어 썼다
(보드 때 `카툰_판자_목표.png` 와 같은 기법).

절차적 구현: 외곽 실루엣은 수학적 원(512.08 ± 0.31px)으로 두고 **잉크선의 안쪽 경계만** 흔든다.
저주파 6성분 + **한 방향 압력항 `-press*cos(a-232°)`**. 무작위로 굵으면 손그림이 아니라 노이즈로 읽힌다.

## STEP 2~3 실측 (Leonardo Nano Banana 2)

| 항목 | 값 |
|---|---|
| 생성물 | **1024×1024 JPEG** (4096으로 뽑았으면 더 좋았다 — 공 728px를 1.42배 확대해야 했다) |
| 적합 원 중심 | (508.94, 510.81) — 캔버스 중심에서 2.65px |
| 적합 반지름 | 363.86px (여백판 이론 379 대비 −15.1px, 4% 작게 그림) |
| 원 적합 잔차 | 평균 **2.27px** / 최대 14.44px |
| 목표 팔레트 반경 26 안 | **99.5%** (캣츠아이 86.9%) |
| 청록 표면 표준편차 | 생성물 5.50 → 팔레트 스냅 후 0.00 |

**잔차가 캣츠아이(0.29px)보다 8배 큰 건 정상이다.** 이번엔 흔들리는 손그림 선을 주문했으니까.

### ★ 새로 배운 것 두 개

1. **생성물은 홍채 잉크선만 굵게 그리고 공 바깥 외곽선은 거의 안 그렸다.**
   외곽 어두운 띠 1.0~23.5px(평균 12.9) vs 마스터 13~72px. 곳곳에서 끊긴다.
   → 실루엣은 원래 우리 영역이므로 **마스킹 후 외곽 잉크선을 절차적으로 복원**했다. 앞으로도 이 순서로 간다.

   ★ **1차 복원은 형락님이 반려했다.** "외곽선의 바깥선은 균일하게 동그래야 해."
   바깥 경계는 완전한 원(511.00 ± 0.000px)이었지만, 안쪽 경계를 흔들 때 두께 하한을 안 둬서
   **붓 압력 반대쪽(52° 부근)에서 띠가 8px까지 얇아져 아이보리가 바깥 경계까지 올라왔다.**
   → **두께를 반지름이 아니라 두께 함수로 직접 파라미터화**하고 하한 24px을 건다:
   `t(a) = max(24, 50 + 10*noise + 16*cos(a-232°))` → 30.5~66.8px(2.2배), 끊긴 방향 0/1440.

   **진단법**: 가장자리를 극좌표로 펴면(가로=각도, 세로=반지름) 바깥 경계가 직선인지,
   띠가 끊기는 구간이 있는지 한눈에 보인다. 원형 그림 검수에 계속 쓸 것.
2. **평탄 셀 아트는 팔레트 스냅으로 JPEG 노이즈를 완전히 지울 수 있다.**
   목표 팔레트와의 거리 58 미만이면 스냅, 그 이상(경계 안티에일리어싱 0.6%)은 원본 유지.
   다운샘플이 없어도 되므로 저해상도 생성물을 살릴 수 있다.

## ★ 공 리소스 확정 (2026-08-03) — 더 안 건드린다

형락님이 최종본 PNG를 직접 지정. **그림은 손대지 않는다.** 다만 두 가지 보정이 필요했다:

1. **캔버스 내접** — 올려주신 파일은 공이 764px인데 캔버스가 1024px이었다.
   `refresh_ball_size()`가 텍스처 긴 변으로 나누므로 44px 요청에 실제로는 **32.8px**로 그려지고
   충돌 39.6px과 6.8px 어긋난다. 구본 `ball.png`가 FAIL난 것과 같은 사유.
   → 원 적합(중심 511.60/511.99, 반지름 378.12, 잔차 평균 1.13px) 후 1024에 내접.
2. **팔레트 정리** — 청록 표면 표준편차가 **15.28**로 보드 원판 FAIL 기준 15.5에 거의 닿았다.
   압축 잡티다. 평탄 셀 아트라 팔레트 스냅(거리 62 미만)으로 **0.00**이 된다. 형태·배치·색상은 불변.

확정 수치: 알파 bbox 1024×1024 · 외곽 잉크 바깥 경계 **511.45 ± 0.114px**(완벽한 원) ·
잉크 두께 8.2~30.8px(44px 환산 0.80px) · 끊김 0/1440 · 목표 팔레트 반경 26 안 99.4%.

**외곽선 두께는 세 번 리테이크했다.** 2.11px → "너무 두꺼워" → 1.10px → "얇게" → 0.61px.
최종본은 0.80px. 44px 기준 잉크선은 **0.6~0.9px가 형락님 취향**이다. 다른 오브젝트에도 적용할 것.

**하이라이트 흰 점 2개는 유지한다.** 한 번 "없애줘" 해서 지웠다가 같은 파일을 다시 올리며
"이걸로 픽스"라고 해서 되돌렸다. → 앞으로 요소를 지우라는 지시를 받으면 **지운 버전과 원본을
같이 보여주고** 확정을 받는다. 지운 결과는 `docs/ball_guides/v7_final/ball_FINAL_nohl_1024.png` 에 보관.
