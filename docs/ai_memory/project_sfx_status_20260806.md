## 한 줄 요약

**핵심 루프의 소리는 전부 만들어 게임에 붙였다.** 음원 25종, 재생 시스템, 시그널
배선까지 끝났고 테스트 5종이 통과한다. 남은 것은 **귀 검수와 커밋**, 그리고
코드에 아직 존재하지 않는 오브젝트(코인·보스·수리부품)의 소리다.

## 1. 완료

### 1-1. 음원 25종

- [x] **벽 충돌 3종** — 저·중·고속. 속도 구간으로 갈린다 (랜덤 아님)
- [x] **플리퍼 6종** — 선택 · 작동 · 일반타격 · 강타격 · 복귀 · 패링
- [x] **공 흐름 2종** — 발사(당긴 힘에 따라 음량 변화) · 낙하
- [x] **콤보 4종** — 상승(피치 사다리) · 단계 · 실패 · 목표 도달
- [x] **웨이브 2종** — 승리 · 패배
- [x] **범퍼 8종** — 단추 · 솜 · 용수철 · 북 · 대포몸통 · 대포발사 · 파괴 · 리스폰

제작 방식은 **ElevenLabs 재질 + 절차적 마감**이다. AI 에서 재질만 가져오고
길이·엔벨로프·dB 는 스크립트가 확정한다. 그대로 넣으면 "패링이 타격보다 길어야
한다", "복귀 < 선택 < 작동 < 타격" 같은 기획서 규격이 전부 깨진다.

- 25종 중 **24종이 AI 소재**, 1종(대포 발사)은 절차적 대체본
- 음량 서열은 파일에 구워져 있다. 코드에서 또 깎지 않는다
- 무손실 PCM 임포트(`compress/mode=0`) — 기본값 QOA 는 어택을 흔든다

### 1-2. 재생 시스템 (스크립트 15개)

- [x] **우선순위 목소리 풀** — 16 목소리, 클래스별 예약·하드캡, 우선순위 스틸링
      `패링 > 보스 > 플리퍼 > 공·범퍼 > 벽 > 앰비언트`
- [x] **벽 하드캡 4** — 기획서 "최대 동시 재생 4개"가 여기서 구현된다
- [x] **패링 래치** — 같은 물리 프레임에 패링이 있으면 낮은 소리는 요청조차 안 간다
- [x] **연타 감쇠** — 최소 간격 0.04초, 두 번째부터 −3dB (바닥 −9dB)
- [x] **피치 랜덤 ±5%** — 파일에 굽지 않고 런타임 처리
- [x] **오디오 버스** — Master(리미터) / SFX / BGM

### 1-3. 시그널 배선

기존 스크립트를 **한 줄도 고치지 않고** 이미 있던 시그널에 붙였다.

- [x] `wall_contact_registered` / `flipper_contact_registered` → 충돌음
- [x] `parry_resolved` → 패링음 (등급별)
- [x] 플리퍼 `state_changed` → 작동 · 복귀음
- [x] `ball_launched(ball, dir, speed)` → 발사음 (speed 로 음량)
- [x] `ball_drained` → 낙하음
- [x] `combo_changed` → 상승음 (콤보 수로 피치 사다리)
- [x] `combo_tier_changed` → 단계음 (오를 때만)
- [x] `combo_finished` → 실패음 (점수 0일 때만)
- [x] `target_score_reached` → 웨이브 승리음
- [x] `wave_balls_exhausted` → 웨이브 패배음
- [x] `response_resolved` → 범퍼 5종 (`bumper_kind_id` 로 갈림)
- [x] 범퍼 `state_changed` → 파괴 · 리스폰 예고음
- [x] `control_started` / `control_ended` → 대포 조작 · 발사음

## 3. 알고 있어야 할 것

### 3-1. 필터 기준을 두 번 고쳤다

- **피크로 무음을 판정한 것이 틀렸다.** 저역 위주 소리는 정상이어도 피크가 낮다.
  장난감 북·콤보 실패음 12개가 탈락했는데 실제 SNR 은 41~56dB 인 깨끗한 저음이었다.
  → **SNR 기준**으로 교체
- **SNR 만으로도 부족했다.** 대포 발사음 하나가 SNR 62dB 로 통과했는데
  에너지의 99.9%가 50Hz 아래인 **압력 계단**이었다. 소리가 아니다.
  → **"120Hz 위에 에너지가 있는가"** 추가

### 3-2. AI 프롬프트에서 배운 것

- **소리 명사가 결과를 지배한다.** `knock` 을 시키면 유리를 요구해도 나무를 준다
- **물체는 하나만.** 둘을 넣으면 모델이 충돌 장면을 만든다
- **작은 소리를 달라고 하면 안 된다.** 음량은 런타임이 건다.
  작게 달라고 하면 노이즈 플로어를 받는다
- 최종 수율 — 플리퍼 14/54, Tier 3·4 는 54/96

### 3-3. Godot 함정 (다른 작업자도 당할 수 있음)

- `.tscn` 에 아직 등록 안 된 `class_name` 의 프로퍼티가 적혀 있으면,
  에디터가 씬을 다시 저장하며 **그 프로퍼티를 조용히 지운다.** 에러도 경고도 없다
  → 순서: 스크립트 작성 → 클래스 등록 → 씬 편집 → 검증
- `node_paths=PackedStringArray(...)` 는 **Node 타입 익스포트 전용**이다.
  `NodePath` 타입에 쓰면 조용히 빈 값이 된다
