# 보드 스펙 (2026-08-02 확정)

## ⚠ 먼저 — 초기 검증은 틀렸다 (전제 오류)

처음에 "명시 수치가 1920×1080을 초과해서 불가능"하다고 판정하고 보정안(사각형 대각 634px,
삼각형 W1 894px 등)을 냈으나 **전부 무효**다.

**틀린 전제**: 보드 좌표 = 화면 픽셀이라고 1:1 매핑을 가정했다.
**실제**: Godot은 월드 유닛으로 설계하고 `Camera2D.zoom`이 화면에 맞춘다. 화면 픽셀 상한이라는 제약은 없다.

스펙에 적힌 px는 전부 **월드 유닛**이지 화면 픽셀이 아니다. 앞으로 이 혼동을 반복하지 말 것.

---

## 확정 기준

> **화면 비율 16:9 고정 · 보드 설계 캔버스 2240 × 1260 월드유닛 · Camera2D zoom 0.857**

`zoom = 1920 ÷ 2240 = 0.857`

2240×1260은 임의로 정한 값이 아니라, 스펙의 사각형 보드(수직변 700 / 대각 820)를
16:9로 풀면 정확히 2241.2 × 1260.7이 나오는 데서 역산된 값이다.
→ **스펙이 처음부터 16:9에 맞게 설계돼 있었다.**

### Godot 설정 (변경 필요)
| 항목 | 현재 | 변경 |
|---|---|---|
| Viewport (project.godot) | **미설정** → Godot4 기본 1152×648 | **1920 × 1080 명시** |
| Stretch mode / aspect | canvas_items / **expand** | canvas_items / **keep** |
| Camera2D zoom (씬) | 0.56 | **0.857** |
| BoardBackground polygon | 1864 × 1024 | **2240 × 1260** |

뷰포트가 명시돼 있지 않은 게 위험. 누가 프로젝트 설정을 건드리면 전부 틀어진다.

## 1. 사각형 보드 (메인, 팔각형)

- 플리퍼 그룹 4개 · span **700** = 서브 328 + 갭 44 + 서브 328 · 센서 328×88
- 충돌 두께 24 · 시각 최대폭 34 · 안쪽 스트로크 18
- F1 상단(수평) / F2 우측(수직) / F3 하단(수평) / F4 좌측(수직)
- 고정벽 4개 대각 **820** (충돌 24, 시각 6) — 명시 수치 그대로
- 리밸런스: 공 r22 · 발사 940 · 최소 320 · 최대 1540 · 패링최대 1700 ·
  작동 0.06/유지 0.035/복귀 0.095/쿨다운 0.065 · 판정 0.095/0.042 · 배율 0.86/1.08/1.18 · 각도보정 ±30°

**정점** (캔버스 2240×1260, 외곽 여백 4px, 대각 실측 814.2 ≈ 820)
`(770,4) (1470,4) (2236,280) (2236,980) (1470,1256) (770,1256) (4,980) (4,280)`

※ 비주얼 가이드 문서판은 여백 0px 기준으로 `(770,0) (1470,0) (2240,280) ...` 이고
대각 길이를 819.3px로 적는다. 아트는 820px로 제작해도 된다고 명시돼 있다.

## 2. 삼각형 보드 (육각형)

- F1 좌상단 336×88 ×2 + 갭 48 = span 720 · **−45°**
- F2 우상단 336×88 ×2 + 갭 48 = span 720 · **+45°**
- F3 하단 308×88 ×2 + 갭 44 = span 660 · **0°**
- 고정벽 W1 상단 1180 / W2 우하단 980 / W3 좌하단 980 — 명시 수치 그대로
  ※ W2·W3 각도는 문서에 없음. 980으로 폐합시키면 **38.3°**
- 리밸런스: 공 r22 · 발사 920 · 최소 320 · 최대 1520 · 패링최대 1680 ·
  작동 0.065/유지 0.04/복귀 0.10/쿨다운 0.07 · 판정 0.10/0.044 · 배율 0.85/1.08/1.18 · 각도보정 ±32°

**보드 크기** 2198.2 × 1116.5 — 2240×1260 안에 폭 34 / 높이 136 여유로 들어감. 보정 불필요.

W1 1222 / W2·W3 1090 / 하단 대각 43.5°로 적는다. **문서판과 기획서판이 다르다 — 확인 필요.**

## ⚠ 미해결: 플리퍼 크기가 3종류
- 사각형: **328**×88 (4그룹 전부)
- 삼각형: **336**×88 (F1·F2) / **308**×88 (F3)

비주얼 가이드 2-5의 "표준 플리퍼 하나를 복제·회전, 충돌 크기와 실루엣 동일 유지" 원칙과 충돌.

정석은 세 크기 통일. **형락님 확인 필요.**
