# 수리 부품 아트 (2026-08-06)

기획서: `인형사의 수리 부품 비주얼·사운드 제작 가이드 v0.1` (강보현, 21쪽).
산출물: `docs/repair_part_guides/final/`, `docs/repair_part_guides/candidates/`.

4종 전부 **표시 88px / 충돌 80px** (`settings/bumpers/repair_parts/` 실측).
단추(92px)보다 작아서 3-1절의 "작은 디테일을 제거해도 정체성이 유지되어야 한다"가
특히 빡빡하게 걸린다.

## ★ 다음 사람이 밟기 쉬운 지뢰 3개

### ① 초승달 바늘 — 기획서는 취소, 코드는 구현돼 있다

가이드 **14쪽 4-3절 제목**에 `초승달 바늘은 개발 취소됨, 구현하지 말것` 이 박혀 있다.
그런데 그 아래로 실루엣·색상·상태·VFX·SFX 규격이 그대로 남아 있어 안 읽으면
그대로 만들게 된다. 범퍼 가이드의 장난감 기차와 **같은 함정**이다.

문제는 코드에는 이미 있다는 것이다.

```
scripts/repair_parts/effects/repair_needle_effect.gd
scripts/repair_parts/runtime/repair_effect_router.gd  (needle 분기)
settings/bumpers/repair_parts/CrescentNeedle.tres
settings/repair_parts/CrescentNeedleDefinition.tres
scenes/repair_parts/parts/crescent_needle_part.tscn
```

**아트는 만들지 않았다.** 되살릴지 걷어낼지 PL 확인이 필요하다.

### ② 진행 상태 표시를 그림에 굽지 말 것

`repair_part_feedback.gd` 의 `_draw_pips()` 가 진행도를 **코드로 직접 그린다.**
브로치 2개(`lit_arms`), 톱니 3개(`wind_stack`).

1차 생성물에는 리벳이 그림에 구워져 나왔다. 그대로 붙이면 코드가 그리는 pip 과
**이중으로 겹친다.** 게다가 88px 에서는 구워진 리벳이 어차피 안 보인다.
붙이기 전에 그림에서 빼야 한다.

### ③ 톱니 회전은 레이어 분리가 선행돼야 한다

기획서 11쪽은 1·2단계에 기어가 짧게 돌고 3단계에 한 바퀴 돈다고 한다.
그런데 통짜 그림을 통째로 돌리면 **중심 허브·나사·리벳까지 같이 돈다.**
허브는 수축·팽창만 하고 리벳은 고정이어야 한다.

필요한 레이어는 셋이고, **각 레이어의 회전축이 이미지 정중앙**이어야
`rotation` 만으로 맞물려 돈다.

| 레이어 | 동작 |
|---|---|
| 큰 기어 | 접촉 시 짧게 회전, 3단계에 한 바퀴 |
| 작은 기어 2개 | 큰 기어와 반대 방향 |
| 허브 + 나사 | 고정 |

현재 후보는 전부 한 장에 붙어 있어 분리가 안 된다. **레이어 분리 버전으로
다시 뽑아야 한다.** 미착수.
