# flipper 음원 후보

폴더 앞 숫자는 **오디션 순서**다. 위에서부터 재생하면 된다.
반려본은 지웠으므로 **여기 있는 것은 전부 들어볼 가치가 있는 것**이다.
`_source/` 는 생성 원본이다. 길이를 바꿔 다시 자를 때만 쓴다.

## 1_select

플리퍼 선택 — 방향키로 조작할 플리퍼 그룹을 바꿀 때

판정 기준: 조작 확인음. 짧은 딸깍·단추 (p.20)

- `flipper_select_01.wav`
- `flipper_select_05.wav`

## 2_activate

플리퍼 작동 — Space 로 플리퍼가 올라가는 순간. ★기계 동작음

판정 기준: 스프링 압축 + 짧은 휙. 기계가 실제로 움직이는 소리 (p.20)

- `flipper_activate_01.wav`
- `flipper_activate_02.wav`
- `flipper_activate_06.wav`

## 3_hit

플리퍼 일반 타격 — 플리퍼가 공을 침 (MUST)

판정 기준: 구슬이 플리퍼에 맞는 소리. 유리 성분이 있어야 한다

- `flipper_hit_04.wav`

## 4_strong

플리퍼 강한 타격 — 세게 쳤을 때. 금속 쾅이 아닌 탄력 있는 쫙

판정 기준: 세게 친 것. 금속 쾅이 아니라 탄력 있는 쫙 (p.20)

- `flipper_strong_01.wav`
- `flipper_strong_02.wav`
- `flipper_strong_03.wav`
- `flipper_strong_04.wav`
- `flipper_strong_06.wav`

## 5_return

플리퍼 복귀 — 제자리로 내려앉는 기계 동작음

판정 기준: 작은 태엽 떨림. 있는 줄 모를 만큼 작게 (p.20)

- `flipper_return_02.wav`
- `flipper_return_03.wav`

## 6_parry

정확한 패링 — 리듬천국 탁구 같은 음정 있는 폭

판정 기준: 리듬천국 탁구 — 음정이 있는 짧고 깨끗한 폭

- `flipper_parry_06.wav`
