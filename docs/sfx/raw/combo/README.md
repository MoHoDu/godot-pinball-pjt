# combo 음원 후보

폴더 앞 숫자는 **오디션 순서**다. 위에서부터 재생하면 된다.
반려본은 지웠으므로 **여기 있는 것은 전부 들어볼 가치가 있는 것**이다.
`_source/` 는 생성 원본이다. 길이를 바꿔 다시 자를 때만 쓴다.

## 1_rise

콤보 상승 — 한 음. 피치 사다리는 런타임 (combo_changed)

판정 기준: 한 음. 피치 사다리를 태우려면 음정이 뚜렷해야 한다

- `combo_rise_01.wav`
- `combo_rise_02.wav`
- `combo_rise_03.wav`
- `combo_rise_04.wav`
- `combo_rise_05.wav`
- `combo_rise_06.wav`

## 2_tier

콤보 단계 상승 — 상승보다 크고 밝게 (combo_tier_changed)

판정 기준: 상승보다 크고 밝게. 유리·수정 질감

- `combo_tier_01.wav`
- `combo_tier_02.wav`
- `combo_tier_03.wav`
- `combo_tier_04.wav`
- `combo_tier_05.wav`
- `combo_tier_06.wav`

## 3_timeout

콤보 실패 — 시간 초과로 끊김. 태엽 풀리는 실망 (combo_finished)

판정 기준: 실패. 처지는 느낌이되 120Hz 아래로 가면 스피커가 못 낸다

- `combo_timeout_02.wav`

반려 2개:
- ~~combo_timeout_04~~ — ①가청대역 11.3%(≥15)
- ~~combo_timeout_05~~ — ①가청대역 8.8%(≥15)
