# 받은 음원 넣는 곳 — Adobe Firefly 작업 흐름

2026-08-07 부터 **Adobe Firefly** 로 뽑는다. ElevenLabs 에서 갈아탔다.

## 왜 바꿨나

ElevenLabs 에서 타격음이 계속 무음으로 나왔다. 같은 자리에서 두 번 -47dBFS
(최대 샘플값 165/32767) 가 나왔고, 프롬프트를 아무리 고쳐도 안 됐다.

Firefly 에는 **Voice performance** 가 있다. 목소리를 녹음하면 그 **에너지와
타이밍에 맞춰** 소리를 만든다. 타격음은 순간의 세기가 전부라 이 기능이
문제를 직접 푼다. 실제로 A4 를 이 방식으로 뽑으니 **풀스케일 · SNR 94dB** 가
한 번에 나왔다.

## ★ 프롬프트 방식이 정반대다

| | ElevenLabs | Firefly |
| --- | --- | --- |
| 길이 | 길고 상세하게 | **짧고 간단하게** |
| 오디오 용어 | 알아듣는다 (`one-shot`·`anechoic`) | **쓰지 않는다** |
| 부정문 | 통했다 (`then silence`) | **쓰지 않는다** |

Firefly 문서가 명시한다 — "간단하게 유지하고 한 번에 하나에 집중하라".
공식 예시가 이 정도 길이다: `Pasta sauce sizzling`

그래서 **형용사 + 물체 + 동사** 한 줄이면 끝이다.
ElevenLabs 용 긴 프롬프트를 그대로 붙이면 오히려 방해가 된다.

## 하는 법

1. 프롬프트 한 줄 입력
2. **Voice performance → Record voice** — 원하는 소리를 입으로 **한 번만** 짧게
3. 생성
4. 다운로드 (형식 아무거나 — mp3·m4a 도 받는다. 48kHz WAV 로 변환한다)
5. 아래 폴더에 넣는다

```
inbox/flipper/   A1~A6
inbox/ball/      B1~B6
```

## 파일 이름

**번호만 맞으면 된다.** 뒤에 뭐가 붙든 상관없다.

```
A2.wav   A2_01.wav   A2-3.mp3   A2 아무거나.wav
```

한 역할에 여러 개 넣어도 된다. 측정해서 가장 맞는 것을 고른다.

## ★ 음량은 신경 쓰지 않아도 된다

크게 받는 것이 좋지만, **최종 음량은 반입할 때 맞춘다.**
기획서 우선순위대로 파일에 구워 넣는다.

```
복귀 -16  <  선택 -14  <  작동 -9  <  타격 -4  <  강타격 -2.5  <  패링 -1
```

그러니 **AI 에게 작은 소리를 달라고 하면 안 된다.** 작게 달라고 하면
노이즈 플로어를 받는다. 작아야 하는 복귀음도 크게 받아서 내려야 한다.

## 번호표

| 번호 | 역할 | 기획서 |
| --- | --- | --- |
| A1 | 플리퍼 선택 | 조작 확인 딸깍 |
| A2 | 플리퍼 작동 | 철컥 + 덜컹 |
| A3 | 플리퍼 복귀 | 있는 줄 모를 만큼 |
| A4 | 플리퍼 타격 (MUST) | 단단한 톡/탁 |
| A5 | 플리퍼 강타격 | 금속성 쾅이 아닌 탄력 있는 쫙/팡 |
| A6 | 패링 퍼펙트 | 명쾌한 탁 |
| B1 | 벽 충돌 저속 | 짧은 톡 |
| B2 | 벽 충돌 중속 | 속 빈 둑 |
| B3 | 벽 충돌 고속 | 밝은 팅 |
| B4 | 공 발사 | 당긴 힘으로 음량이 갈린다 |
| B5 | 공 낙하 | 가라앉는 느낌 |
| B6 | 공 선택 | 웨이브 시작 시 공 고르기 |

## 넣은 다음

말만 하면 된다. 측정 -> 판정 -> 마감 -> 반입 -> 검증 -> 씬 실행까지
`build_from_ai.py --only <역할>` 한 번에 돈다.

소재 우선순위는 **받은 파일 > 절차적 합성 > AI 원본** 이다.
inbox 에 파일이 있으면 무조건 그것을 쓴다.
