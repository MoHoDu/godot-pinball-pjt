## ★ 초승달 바늘 — 기획서와 코드가 어긋나 있다

가이드 4-3절 제목에 개발 취소가 명시돼 있는데 그 아래로 실루엣·색상·상태·VFX·SFX
규격이 그대로 남아 있다. 범퍼 가이드의 장난감 기차와 같은 함정이다.

그런데 **코드에는 구현돼 있다.**

```

settings/bumpers/repair_parts/CrescentNeedle.tres
scenes/repair_parts/parts/crescent_needle_part.tscn
```

아트는 만들지 않았다. PL 확인이 필요하다.

## 이 아트에 리벳·별 팔 점등을 굽지 말 것

진행 상태 표시는 **코드가 따로 그린다.** `repair_part_feedback.gd` 의
`_draw_pips()` 가 브로치 2개(`lit_arms`), 톱니 3개(`wind_stack`) 를 직접 그린다.
그림에 구운 리벳은 이 pip 과 이중으로 겹치므로 붙이기 전에 정리해야 한다.
