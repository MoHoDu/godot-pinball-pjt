# 범퍼 아트 최종본

각 범퍼당 한 장씩만 둔다. 후보 전량과 검수 시트는 저장소에 넣지 않는다.

| 폴더 | 내용 |
| --- | --- |
| `masked/` | 배경 제거 + **알파 bbox == 캔버스** 정규화본. 게임에 붙일 때 이걸 쓴다 |
| `unmasked/` | Leonardo 원본 JPG. 다시 마스킹하거나 재생성 기준으로 삼을 때 쓴다 |

`Resources/` 에는 아직 아무것도 넣지 않았다. 범퍼에는 텍스처 슬롯 자체가 없어
(`bumper_visual.gd` 의 `_draw()` 가 도형을 직접 그린다) 개발 선행 작업이 필요하다.

## 선정 내역 (2026-08-06)

| 범퍼 | 채택 | 표시 / 충돌 | 비고 |
| --- | --- | ---: | --- |
| 단추 | `bumper_master_v2.py` 코드 생성 | 92 / 88 | 검수 통과 확정본. 원본 JPG 없음 |
| 솜 | 2차 0번 | 104 / 96 | **공보다 밝다.** 명도 재조정 여지 |
| 용수철 인형 | 3차 0번 | 112 / 104 | 기본 상태. 타격 프레임 미제작 |
| 장난감 북 | 3번 | 128 / 120 | 페넌트가 한 바퀴를 채우지 않아 대칭을 피했다 |
| 구슬 미끄럼틀 | 3번 | 240 / 232 | **코드에 슬롯 없음.** 표시 지름도 가정값 |
| 태엽 대포 | 3번 | 128 / 112 | 포신 +X, 포구가 받침대 원 안에서 끝난다 |

솜 · 용수철 인형은 PL 검토 대기 중이다. 결과에 따라 교체될 수 있다.
