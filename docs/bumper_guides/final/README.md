# 범퍼 아트 최종본

각 범퍼당 한 장씩만 둔다. 후보 전량과 검수 시트는 저장소에 넣지 않는다.

| 폴더 | 내용 |
| --- | --- |
| `masked/` | 배경 제거 + **알파 bbox == 캔버스** 정규화본. 게임에 붙일 때 이걸 쓴다 |
| `unmasked/` | Leonardo 원본 JPG. 다시 마스킹하거나 재생성 기준으로 삼을 때 쓴다 |

(`bumper_visual.gd` 의 `_draw()` 가 도형을 직접 그린다) 개발 선행 작업이 필요하다.
