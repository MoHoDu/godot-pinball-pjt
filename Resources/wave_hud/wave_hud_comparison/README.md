# Wave HUD Panel Background Comparison

Both variants use the same layout, information hierarchy, ball types, slot order, and repair-gauge colors. Only the panel theme and the minimum foreground contrast required by that theme differ.

## Variants

- `wave_hud_dark_panels.png`: current dark teal panel background.
- `wave_hud_ivory_panels.png`: ivory panel background with dark text and borders.
- `life_stock_dark.png`, `life_stock_ivory.png`: isolated life-stock comparison.
- `score_dark.png`, `score_ivory.png`: isolated score-panel comparison.
- `settings_ivory.png`: ivory settings-button theme used by the ivory screen.

## Ball stock states

- Current: full-color type icon with teal outline.
- Remaining: full-color type icon without an outline.
- Used: same type icon at 26% opacity.
- The component supports 3-5 fixed slots without counters or labels.

The official handoff PDF and `wave_hud_layers` exports should be updated after one panel theme is selected.
