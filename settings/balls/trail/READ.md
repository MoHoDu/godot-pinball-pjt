# 공 종류별 이동 꼬리 설정

메뉴 경로: `Pinball > Game Settings > Balls > trail/...`

보상 공 종류별 이동 꼬리 길이와 색상을 설정합니다.

- `길이`: 기준 길이, 속도별 배율, 표시 임계 속도, 기록 점 개수와 수명
- `블룸`: 바깥 꼬리 폭·알파·테이퍼
- `레이저`: 안쪽 밝은 꼬리 폭·알파·테이퍼
- `밝기 계단`: 단계 수와 끝부분 감쇠
- `전환`: 나타남·사라짐 시간
- `색`: 레이저와 블룸의 시작·중간·끝 색

정지 상태에서 잔상이 남지 않는지와 빠른 방향 전환 때 꼬리가 공을 가리지 않는지를 함께 확인하세요.
