# 공 종류별 발광 설정

메뉴 경로: `Pinball > Game Settings > Balls > glow/...`

보상 공 종류별 안개 오라와 코어 링을 설정합니다. 파일명의 공 종류와 실제 Ball Definition의 ID가 일치해야 합니다.

- `형태`: 오라 반경, 알파, 명도 단계, 실루엣 굴곡
- `안개 결`: 결 개수·세기, 진행 방향 늘어짐, 흐름 속도
- `코어 링`: 링 밝기·두께·흔들림
- `점등 반응`: 패링 시 밝기와 유지·복귀 시간
- `상태 색`: 일반, 콤보, 패링, 저주, 위험 색상

공 본체보다 오라가 밝아지지 않게 하고, 공 종류를 추가하면 같은 이름의 glow와 trail 설정을 함께 준비하세요.
