# 음원 대기 중인 규칙들

2026-08-07 처음부터 다시 만들기로 하면서 음원을 전부 지웠다.
이 규칙 파일들은 **지워진 음원을 ext_resource 로 참조**하고 있다.

★ 없는 파일을 참조하는 `.tres` 가 `settings/sfx/` 에 있으면 **다른 규칙까지
  로딩이 깨진다.** 실제로 그래서 남아 있던 A1·A2 까지 무음이 됐다.
  그래서 음원이 준비될 때까지 여기로 빼 둔다.

되살리는 순서
  1. 해당 음원을 Resources/sfx/ 에 반입한다
  2. 이 파일을 settings/sfx/ 로 옮긴다
  3. 씬(`wave.tscn` · `sfx_lab.tscn`)의 바인더에 규칙을 다시 연결한다
