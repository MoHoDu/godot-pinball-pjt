# 범퍼 설정 구조

이 폴더는 범퍼 기능별 설정을 나눠 보관합니다. 직접 `.tres`는 없으며 아래 하위 폴더를 사용합니다.

- `stage_01`: Stage 01 프로덕션 범퍼 수치와 배치
- `stage_01_compact`: 작은 화면·축소 보드용 범퍼 변형
- `repair_parts`: 보드에 장착되는 수리 부품형 범퍼
- `presentation`: 이름·아이콘·설명 등 표시 정보
- `anim`, `vfx`: 애니메이션과 타격 연출
- `test`: 자동·수동 테스트 전용 값

같은 범퍼를 수정할 때 수치, 표시 정보, 애니메이션, VFX 파일이 따로 있을 수 있으므로 파일명의 종류를 맞춰 확인하세요.
